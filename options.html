♛︎Ask Queen settings

Ask Queen works without any setup. These settings help when the free servers run out of quota or stop answering.

Hugging Face token (optional)

Queen runs on free community GPUs that answer only a few questions per visitor. A free Hugging Face token raises that limit. Create a token on Hugging Face (opens in a new tab).

Your token is sent with every question to the Queen servers. They are run by community members, not by Hugging Face, Princeton or this extension's author, and the people who run them could read it. Use a read-only token made just for Ask Queen, with no access to your private models or data, and revoke it on Hugging Face when you no longer need it.

No token saved.

The token stays in this browser and is never synced. Once saved it is shown only by its last four characters.

Server

Both built-in servers run the same model. If the first one doesn't answer, Ask Queen tries the other once.

Custom server (optional)

If you run your own copy of a Queen Space on Hugging Face, Ask Queen can use it. Chrome will ask you to allow that one address, and nothing else.

No custom server saved.

Enter the address first. Leave this off unless you trust whoever runs that server: without it, questions go there with no token. The choice covers that one address, and changing the address clears it.
